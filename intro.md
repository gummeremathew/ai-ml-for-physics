# AI for Physics

Welcome to the course site for **AI for Physics**, a new course in the CWRU Department of Physics.

## About the course

Machine learning and AI tools are showing up everywhere in physics research, from sorting particle collisions to simulating calorimeter showers. This course teaches you what those tools are, how they work, and most importantly, how to pick the right one for the problem in front of you.

A big focus of the course is **tool-leveling**: choosing a tool that is as powerful as the problem needs and no more. Can a clustering algorithm handle this, or does it actually need a neural network? When is a large black-box model worth the cost, and when is it overkill?

Each unit is built around one tool. You'll get an introduction to how it works, a real physics dataset to analyze, Python exercises, and a look at what the tool produced and whether you should trust it.

See the [syllabus](syllabus.md) for units, prerequisites, and course policies.

## About the project

This course is being developed as a senior project in the CWRU Physics department. Where possible, exercises use real data and problems from CWRU faculty, so the work reflects what people in the department are actually doing. These are supplemented with public datasets from outside CWRU.
