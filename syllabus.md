## Course description

This course introduces the machine learning and AI tools used in modern physics research, how they work, and how to choose between them. The emphasis is on tool-leveling: matching the complexity of the tool to the complexity of the problem. Students work with real physics datasets, some from CWRU faculty research, and write Python to apply each tool and critically evaluate its results.

## Learning goals

By the end of the course, students should be able to:

- Describe how the major ML and AI tools used in physics work at a conceptual level
- Apply each tool to a real physics dataset in Python
- Choose an appropriate tool for a given problem and justify that choice
- Evaluate a model's output and recognize when it should not be trusted

## Prerequisites

PHYS 250 (Computational Methods in Physics) or equivalent Python experience. Relevant Python and numerical topics will be briefly reviewed, not taught from scratch.

| 4 | Transformers | Sequence models and attention, applied to physical time series. |

## Unit structure

Each unit runs about 9 lectures and includes:

- **Lectures** introducing the tool and how it works
- **Weekly quizzes** (one per three lectures): short written conceptual questions answered in class in a couple of minutes
- **At least one homework assignment**: a Python notebook applying the tool to a physics dataset

There are no labs.
